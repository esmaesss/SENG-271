# Code Version Notes (Code v1–v6) — Template

Each code version gets a Git tag and a short release note; together they are your evidence of incremental development.

*Guidance: Fill one copy of the form below for every code version and paste it into the description of the GitHub Release for that tag. Keep it short and specific.*

| Version | Tag | Expected focus |
